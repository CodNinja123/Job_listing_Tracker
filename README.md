# Python Job Listings Web Scraper

A web scraping application built with Python using BeautifulSoup to extract real-world job posting details and organize them into clean, structured data formats.

## Features
* **HTML Dom Parsing:** Targets specific page container models dynamically.
* **Inline Element Selection:** Cleans extra whitespace strings using native text manipulation methods.
* **Tabular Storage Extraction:** Exports formatted items directly into structured CSV storage blocks.

## Technologies Used
* Python 3.x
* Requests
* BeautifulSoup4 (bs4)
* CSV Module
